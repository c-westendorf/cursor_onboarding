The Reframe

Your Monday Morning Is Already an Agent

Before we talk about infrastructure, let's talk about what you do without thinking.

// You open Slack. You scan.

// You route based on signal type

What you just did

You ran a skill

You took an ambiguous input, applied a learned pattern, routed it to the right response, and produced a structured output. That's a skill.

The only difference with an agent

Key insight

Rules never change per task. Skills are called when relevant. Code only runs when a skill triggers it. This separation is what makes the system safe, predictable, and scalable.

Why intent classification is its own skill

Routing can't route itself

Before the router can act, something has to read the scoped question and decide: diagnostic or exploratory? Retention or acquisition? That judgment is a skill — with triggers, logic, and a structured output the router consumes.

You already do this

"Is this a data pull or a strategic question?"

That split-second classification before you respond to a Slack message — that's intent classification. The agent just needs it written down.

Skill Anatomy

What's Actually Inside a Skill

A skill isn't magic — it's structured expertise. Three parts. Click to open each.

① Trigger — When should this skill activate? ▼

The trigger is a description of the situations this skill applies to. The router reads it to decide whether to invoke the skill.

trigger: "Use when someone asks about
weekly work prioritization, standup,
or what to focus on today"
② Instructions — How should it behave? ▼

Step-by-step guidance that shapes how the model responds. This is where your domain knowledge lives. It's basically a very good brief.

// From the Agile Companion skill:
1. Fetch active Jira stories
2. Rank by sprint deadline proximity
3. Ask: "What's your energy like today?"
4. Never overwhelm — max 6–8 stories
③ Output — What does it produce? ▼

A skill always produces something structured and reusable — not a one-off response. That output might feed into another skill, a tool, or a stakeholder deliverable.

output: {
  focus_rank: [list],
  top_3_today: [stories],
  standup_draft: string
}
"A skill is your judgment, written down precisely enough to be repeatable."
